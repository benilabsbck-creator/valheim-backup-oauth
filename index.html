Valheim Backup

Ferramenta pessoal para manter uma cópia de segurança dos dados de um servidor privado de Valheim no Google Drive do próprio operador.

Como funciona

Uma rotina na máquina virtual prepara arquivos de backup, usa o rclone para enviá-los ao Drive e confere a cópia enviada. O aplicativo solicita acesso apenas aos arquivos do Drive criados ou abertos por ele.

Não há cadastro de outros usuários nem compartilhamento público dos backups.

Leia a Política de Privacidade para entender os dados acessados e como revogar o acesso.
